## Projects

### [Career Assistant](https://github.com/geogr4ze/Career-Assistant)
**JavaScript · Google Apps Script · Google Sheets · Twilio · ChatGPT**

The system runs in the cloud and includes configurable notification rules, quiet hours, duplicate prevention, and daily usage limits.
